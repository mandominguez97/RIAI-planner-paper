# Multi-UAV Architecture for Collaborative Perception and Task-Oriented Planning

The use of swarms of unmanned aerial vehicles (UAVs) increasingly demands advanced autonomous capabilities to perceive the environment, coordinate multiple platforms, and execute tasks safely and efficiently in complex and dynamic scenarios. In this context, this work presents a multi-UAV architecture oriented toward task-based missions that integrates cooperative perception, planning, and navigation within a unified perception-decision-action cycle. The system enables robust detection and georeferencing of fiducial markers through the fusion of distributed observations and transforms this information into a joint task-assignment and collision-free trajectory planning problem. This problem is solved iteratively using candidate trajectories generated with RRT* and the Kuhn–Munkres algorithm. A navigation module specifically designed for aerial robot swarms enables coordinated execution and supervision. The proposed method is validated through several simulations with different numbers of aerial robots, showing significant improvements in efficiency and total mission time compared to decoupled approaches, while maintaining a comparable computational cost.
